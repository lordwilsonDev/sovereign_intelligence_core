# ADR-001

## Title
HCL Strict Default With Environment Opt-Out

## Context
The API needs executable contract verification with local bypass for development workloads.

## Decision
Use strict HCL enforcement as the default. Allow local bypass only via environment variable.

## Alternatives Considered
Postgres-backed enforcement store

## Rejected Because
Single-user deployment favors local env var opt-out over external dependency.

## Consequences
All new endpoints must opt-in or honor the bypass flag consistently.
